# Architecture Decisions

Event-driven (reliability, decoupling). SQS (buffer, retry). DLQ (isolation). Outbox (atomicity). DynamoDB (scalable, GSI). Private S3 (security). Bedrock + rules (semantic + deterministic). Rekognition (image intelligence). CDK (IaC). OIDC (no hardcoded keys). Limitations: AWS deployment blocked; no production Lambda verified.
